Onitama Pocket, by Bonitato82. Full info, images and playing on a browser in https://boniato82.itch.io/onitama-pocket

This is a game boy & game boy color adaptation of the classic abstract strategy game by Shimpei Sato, inspired by the excellent version for PICO-8 by Mischa_u, in itch.io
Onitama is a turn-based game, similar to chess, but simpler. Each player controls a Master and four students, using a shared set of five movement cards that constantly rotate between players. There is no randomness during the match, if you don't like your cards... use them and send them to the opponent!
Win by capturing the enemy Master (with any of your pieces) … or by reaching red temple (start position of each Master) with your Master.

You also lose if your Master is captured or opponent Master reach your temple, so be careful!

**Features**
* Classic Onitama rules (16 cards of  the based game, randomly chosen at the beginning of each game)
* Turn-based tactical gameplay
* AI opponent with strategic behavior (3 difficulty levels: student (easy) < master (normal) < legend (hard))
    * 2 players mode: you can play with a friend...
        ... on the same device (hotseat / Pass-and-play )
        ... with 2 devices, 2 games and a cable link (game link mode)
* Quick matches, high replayability in 32KB ROM
* fully compatible with GBC and GB modes and original hardware (however, game is intended to be played on GBC mode. GB (DMG) mode while playing against legend is a bit slow for each CPU move; around 10-20 seconds).
* Game made with GBDK 4.5.0 (huge thanks to the developers for this amazing tool!)

**Controls**
Game Boy / Emulator
* D-Pad → Move cursor
* A Button → Select a piece, confirm move
* B Button →  Change selected card for movement
* SELECT+A+B → Reset game and return to title screen (hold them for a second)
